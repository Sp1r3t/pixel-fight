# Brakk: уточнённая ульта

Встроенная генерация изображений. Референс: нижний левый Brakk на `characters-01-rook-mira-brakk-juno.png`.

Сохранить крупного бородатого бойца в жилете с мехом, коричневых брюках и наколенниках. Добавить крюк на тяжёлой цепи для ульты. Прозрачный лист 4×4, 16 полных кадров одинакового масштаба: подготовка → достаёт крюк → раскручивает цепь → бросает → упирается и тянет → собирает цепь → руки для захвата → приседает → поднимает жертву над собой → прыжок → бросок вниз → приземляется → ударная волна → возвращается в стойку.

Жертва рисуется отдельным листом на её собственном скине; никаких силуэтов жертвы внутри кадров Brakk. Голова вращается вместе с плечами, колени и стопы естественные. Все цепи, крюки, тело и эффекты целиком внутри своей ячейки. Между ячейками прозрачные промежутки.
