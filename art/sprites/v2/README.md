## Подключение в Roblox

В `asset-ids.json` сохранены 85 ID со скриншотов загрузки. Полные комплекты есть у
Juno, Dax, Wren, Pike, Zip, Ashka и Morrow. Остальные бойцы пока используют прежние
листы, пока не будут добавлены все шесть страниц. После изменения ID нужны
синхронизация Rojo или новая сборка и публикация места.

На скриншотах пока нет: `rook_3`, `mira_1`, `brakk_6`, `sable_6`, `sorren_1`,
`sorren_6`, `glacia_5`, `tempest_5`, `byte_2`, `astra_2`, `astra_4`.

`icons` (ID `116578458341999`) — обзорный лист с непрозрачным фоном.
Интерфейс уже использует те же 46 пиксельных иконок через `PixelIcons.luau` и
`IconGlyph.luau`, поэтому этот ID не подставляется вместо отдельной иконки.
Портреты и `roster` не являются страницами анимаций; старые листы `_a`/`_b`
сохранены только как резервные изображения.

1. Загрузите 6 атласов выбранного бойца (`rook_1.png` … `rook_6.png`) как изображения
   через Asset Manager Roblox Studio. Можно загрузить все 96 атласов сразу.
   Не загружайте `roster.png` и `*-portrait.png` вместо атласов.
2. Скопируйте `asset-ids.example.json` в отдельный файл `asset-ids.json`.
   Укажите image ID строками напротив соответствующих имён файлов. Пустые записи
   других бойцов допустимы; для подключаемого бойца нужны все шесть страниц.
3. Из корня проекта:

   ```text
   node tools/pixelart/import-arcade.js art/sprites/v2/asset-ids.json
   ```

   Импортёр проверяет имена и ID и обновляет `CharacterSpriteUploads.luau`,
   сохраняя ранее подключённых бойцов. Следующая синхронизация Rojo или сборка
   подключит новый арт. Старые ID в `CharacterSprites.luau` сохранены как резерв.

   Если часть ID ещё не получена, добавьте `--allow-incomplete`: будут подключены
   только полные комплекты, а недостающие страницы появятся в выводе.

## Формат

- 128×128 пикселей на кадр, непрозрачные цвета и прозрачный фон; Pixelated в игре.
- 16 кадров на обычную анимацию, 64 кадра на ульту; 8 колонок, перенос после кадра 7.
- 4 обычные анимации на страницу; страницы 1024×1024. Шестая страница отведена ульте.
- 20 анимаций: три разных удара рукой, удары ногой, отдельные удары сидя и в воздухе,
  особый приём, ульта, защита, ходьба, победа и поражение.
- 16 разных стоек с двумя видимыми руками и неподвижными стопами.
- У ульты есть заряжающиеся лучи, ударные кольца, искры и шлейф у кисти или оружия.
- Стойка занимает 2 секунды: лёгкое движение груди, головы и рук, неподвижные ноги.
- Контактная фаза атак занимает среднюю треть шкалы, как в AnimationSelect.
- `manifest.json` и `ArcadeSpriteLayout.luau` генерируются из одной спецификации.

## Перегенерация и проверки

```text
node tools/pixelart/generate-arcade.js
node tools/pixelart/generate-icons.js
node tools/pixelart/check-arcade.js
lune run tests/run.luau SpriteArt Boot Touch CombatNet
```

Рисунки строятся кодом из угловатых полигонов, с анатомическими тенями,
складками ткани, лицами и деталями экипировки. Исходники: `arcade.js`,
`arcade-poses.js`, `icons.js`. Старый генератор `generate.js` оставлен для v1.
