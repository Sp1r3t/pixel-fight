# Бойцы в боевых костюмах

Эта папка содержит актуальные изображения. В Rook, Brakk и Sable переработаны
все кадры и портреты: синий закрытый костюм с красным поясом, броня поверх
серой формы и тёмный костюм ниндзя соответственно. Открытого торса у них нет.
Анимации и раскладка страниц сохранены: 20 движений, 64 кадра ульты, 6 атласов.

`preview.html` — просмотр всех анимаций; `roster.png` — обзор внешности.
Одобрение изображений Roblox определяется модерацией платформы.

## Текущее подключение

Все 96 ID получены: 16 бойцов имеют по шесть страниц. Новые костюмы Rook,
Brakk и Sable используют ID последней загрузки из v4; старые одноимённые
ресурсы со следующих скриншотов не заменяют их. В `asset-ids.json` сохранён
полный актуальный набор. `upload-needed`, `upload-combat` и v4 — ранее
подготовленные наборы загрузки, повторно загружать их сейчас не требуется.

## Загрузка изменений

Последний набор для полного подключения всех бойцов включал 26 PNG: 18 новых
атласов в костюмах и 8 страниц, ID которых не было на предыдущих скриншотах.
Все они собраны в `upload-needed`. Внутри этой папки только нужные PNG;
точный список также сохранён в `upload-needed-list.txt`. Набор создаётся командой
`node tools/pixelart/prepare-needed-upload.js` из текущего `asset-ids.json`.

В `upload-combat` собраны только 18 изменённых атласов, без портретов и обзорных
листов. Загрузите изображения из этой подпапки:

- `rook_1.png` … `rook_6.png`
- `brakk_1.png` … `brakk_6.png`
- `sable_1.png` … `sable_6.png`

Портреты обновлены локально, но не нужны для подключения игрового бойца:
меню берёт изображение из первого атласа. Старый `rook-portrait` с ID
`85581118198017` нигде в игре не используется. `roster.png` тоже не нужен для игры.
Не загружайте повторно прежние изображения из v2.

В `asset-ids.json` перенесены только ID атласов, которые остались побайтно
одинаковыми с v2. Для Rook, Brakk и Sable вписаны ID новых изображений в костюмах;
их прежние ID не используются. Процедурные одетые модели остаются резервом,
если новый полный комплект отсутствует в конфигурации.

После получения новых ID заполните соответствующие строки и выполните:

```text
node tools/pixelart/import-arcade.js art/sprites/v3/asset-ids.json --allow-incomplete
```

Импортёр отвергает старые ID изменённых костюмов. После импорта синхронизируйте
Rojo или соберите игру заново. Иконки интерфейса рисуются из кода и перезагрузки
изображений не требуют.
