# Тестовая сборка

`src/shared/Config/TestMode.luau`: `UnlockAllCharacters = true` временно открывает
всех 16 бойцов в меню и на сервере. Разблокировки не записываются в сохранения.
Поставьте `false`, чтобы вернуть обычные покупки и ограничения доступа.

Спрайты используют постоянный ImageLabel для каждой страницы и предварительную
загрузку ImageLabel. Страница выбирается и кадры обновляются независимо от
IsLoaded: скрытая прозрачная страница больше не ждёт загрузки перед показом.
Подмена на процедурные модели удалена. Ошибки загрузки выводятся в Output
с префиксом [PixelFight] и ID изображения. Недоступный на стороне Roblox
ассет по-прежнему требует решения причины отказа; код не заменяет его другим артом.
Меню открывает всех бойцов сразу, ещё до получения профиля с сервера.

Обычные удары стали короче на 10–16%: замах и восстановление сокращены,
активные кадры и урон сохранены. Это относится к рукам, ногам, приседу и воздуху.
PNG повторно загружать не нужно: анимация синхронизируется с новой фреймдатой.
